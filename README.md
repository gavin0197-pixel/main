# PPT 사진 배치 매크로 생성기

PowerPoint에서 **기준 개체(표/도형) 안쪽 격자에 사진을 자동 배치하는 VBA 매크로**를 만들어 주는 Python GUI 프로그램입니다.
행·열 개수와 **열마다 너비, 행마다 높이**를 cm로 지정하고, 텍스트가 들어가는 칸은 클릭해서 제외할 수 있습니다.

## 실행

Python 3.10 이상 (Windows용 Python 설치 시 tkinter 포함, 추가 패키지 불필요)

```bash
python -m ppt_macro_gen
```

### Windows EXE (파이썬 없이 실행)

- **다운로드:** GitHub 저장소의 **Releases**에서 `PPT_Photo_Macro_Generator_v<버전>.exe`를 받아 바로 실행합니다.
  (`__version__`을 올려 푸시하면 GitHub Actions가 Windows에서 빌드해 Release `v<버전>`을 자동으로 만듭니다.
  버전을 안 올린 푸시도 Actions → 해당 실행 → Artifacts에서 EXE를 받을 수 있습니다.)
- **직접 빌드 (Windows):**

```bash
pip install pyinstaller
```

```bash
python build_exe.py
```

→ `dist/PPT_Photo_Macro_Generator_v<버전>.exe`

## 버전

현재 버전은 GUI 창 제목과 상단 오른쪽, EXE 파일명·속성, 생성된 VBA 코드 머리 주석에 표시됩니다.
변경 내역은 `CHANGELOG.md`. 수정 시 `ppt_macro_gen/__init__.py`의 `__version__`만 올리면 모든 곳에 반영됩니다.

## 사용 순서

1. **프리셋**을 고르거나 직접 입력
   - **격자 탭**: Sub 이름, 행/열 개수, 열 너비·행 높이(cm), 격자 시작점, 번호 순서(행 우선/열 우선)
   - **사진 탭**: 사진 크기 — `칸 크기 − 여백`(칸 크기가 달라도 자동) 또는 `고정 크기(칸 정중앙)`, 테두리,
     원본 비율 — `늘려서 맞춤` / `비율 유지(여백)` / `잘라서 꽉 채우기`(+ **시료 자동 감지**: 흰 배경과 다른 부분을 찾아
     시료가 잘리지 않게 자름. Windows 기본 WIA 사용, 추가 설치 없음)
   - **가져오기 탭**: 파일 선택 창 / PPT에서 선택한 사진 / 폴더의 1,2,3… 번호 파일
2. **미리보기에서 칸을 클릭**해 텍스트 칸을 `제외`로 바꿈 → 사진 번호가 자동으로 다시 매겨짐
3. **코드 복사** → PowerPoint `Alt+F11` → 삽입 → 모듈 → 붙여넣기
   또는 **.bas 저장** → VBA 편집기 → 파일 → 파일 가져오기
4. **설정 저장/열기**(JSON)로 배치별 설정을 따로 보관

좌표 기준: 기준 개체 왼쪽 위 = (0, 0), 단위 cm. 생성된 코드 머리 주석에 설정이 모두 기록되고,
각 사진 박스 좌표가 `slotX(i) = …` 형태로 나열됩니다.

## 프리셋 (ChatGPT 작업 이력 기준, `docs/chatgpt-handover.md`)

| 프리셋 | 내용 |
|---|---|
| 최신 | 파일 선택 6장, 왼쪽 1.46cm 열 제외 + 6.7×4.7 칸 2×3, 사진 6.5×4.5, 테두리 0.75pt |
| G | 선택 사진 6장 2×3, 6.4×4.4, 간격 0.1, 시작 +0.05/+0.79 |
| E | 선택 사진 15장 3×5, 4.7×2.98, 피치 4.85/3.82, 시작 +0.05/+0.79 |
| M | 선택 사진 1장 9.9×6.9, 시작 +0.1/+0.1 |

## 동작 메모

- 휴대폰 사진(EXIF 회전)은 PowerPoint 가 도형을 90/270° 회전시켜 넣으므로, 회전을 감지해 화면상 크기를 맞춥니다.
- 표 셀 안에 커서가 있는 상태(텍스트 편집)여도 표 전체를 기준 개체로 사용합니다. `Cell.Selected`는 쓰지 않습니다.
- 파일 정렬 기본값은 숫자 인식(`2.jpg` < `10.jpg`). 기존 방식(문자열 순)도 선택 가능.
- 보조 함수 이름에 매크로 이름을 붙여(`Fit_<이름>` 등) 여러 매크로를 한 프로젝트에 넣어도 충돌하지 않습니다.
  단, `Option Explicit`은 모듈 맨 위에만 올 수 있으므로 한 모듈에 여러 개를 붙일 땐 체크를 끄세요.
- `.bas`는 cp949로 저장됩니다(한국어 Windows VBA 편집기 가져오기용).

## 한계 / 다음 단계

- 생성 코드는 실제 PowerPoint에서 아직 실행 검증하지 않았습니다.
- 병합 셀(여러 칸에 걸친 사진 칸)은 아직 지원하지 않습니다.
- 표의 실제 열/행 크기를 PPT에서 자동으로 읽어오지 않습니다(입력값 사용).
